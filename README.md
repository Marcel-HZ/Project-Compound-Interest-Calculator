# 复利计算器设计文档

## 一、项目概述

本项目实现了一个**复利计算器**，基于两个核心公式：

1. **基础复利公式**

$$F = P \times (1+i)^n$$

2. **有效年利率（EAR）公式**

$$EAR = \left(1 + \frac{R}{M}\right)^{M} - 1$$

用户通过命令行交互，逐个输入变量（数值或"未知"），程序自动识别唯一未知量并求解；若未知量过多，则提示无法计算。

---

## 二、变量说明

### 2.1 基础模式变量

| 符号 | 名称 | 含义 | 示例 |
|------|------|------|------|
| F | 终值 / 未来值 | 期末总金额 | 121 |
| P | 现值 / 本金 | 期初金额 | 100 |
| i | 每期利率 | 每一期的实际利率 | 0.05 表示 5% |
| n | 期数 | 复利总期数 | 2 |

### 2.2 EAR 模式变量

| 符号 | 名称 | 含义 | 示例 |
|------|------|------|------|
| R | 名义年利率 | 银行挂牌利率 | 0.12 表示 12% |
| M | 每年复利次数 | 一年内计息次数 | 12 表示按月复利 |
| EAR | 有效年利率 | 考虑复利后的真实年利率 | 0.126825 表示 12.6825% |
| t | 年数 | 投资年限 | 2 表示 2 年 |
| F | 终值 | 期末总金额 | 1269.73 |
| P | 现值 | 期初金额 | 1000 |

## 三、公式关系

### 3.1 基础复利

$$F = P \times (1+i)^n$$

四种变形：

| 求解 | 公式 |
|------|------|
| F | $F = P(1+i)^n$ |
| P | $P = \dfrac{F}{(1+i)^n}$ |
| i | $i = \left(\dfrac{F}{P}\right)^{1/n} - 1$ |
| n | $n = \dfrac{\ln(F/P)}{\ln(1+i)}$ |

### 3.2 EAR 与名义利率

$$EAR = \left(1 + \frac{R}{M}\right)^{M} - 1$$

反解名义利率：

$$R = M \times \left[(1+EAR)^{1/M} - 1\right]$$

### 3.3 三种口径的等价性

$$(1+EAR)^t = \left(1+\frac{R}{M}\right)^{Mt} = (1+i)^n$$

其中：

- 每期利率 $i = R / M$
- 总期数 $n = M \times t$

三者在数值上完全等价，只是利率和期数的**口径**不同。

### 3.4 变量关系图

```
        R（名义年利率）
        M（每年复利次数）
        │
        ├──► EAR = (1 + R/M)^M - 1
        │
        ▼
        i = R / M       n = M × t
        │
        ▼
        F = P × (1 + i)^n = P × (1 + EAR)^t
```

## 四、关键问题处理

### 4.1 偶次方双根问题

当求解 $i$ 时，方程为：

$$(1+i)^n = \frac{F}{P}$$

设 $x = 1+i$，则 $x^n = F/P$。实数解情况如下：

| n 的奇偶 | F/P 符号 | 实数解 |
|----------|----------|--------|
| 奇数 | 正 | 一个正根 |
| 奇数 | 负 | 一个负根 |
| 偶数 | 正 | **两个根** $x = \pm(F/P)^{1/n}$ |
| 偶数 | 负 | 无实数解 |

**示例：**

$$121 = 100(1+i)^2 \Rightarrow 1+i = \pm 1.1 \Rightarrow i = 10\% \text{ 或 } -210\%$$

- $i = 10\%$：金融上有意义
- $i = -210\%$：数学上有解，但意味着本金亏光并倒欠，金融上无意义

程序会**同时列出两个解**，并标注哪些是金融上有意义的解。

### 4.2 未知量数量判断

| 未知量个数 | 处理方式 |
|------------|----------|
| 0 | 提示无需计算 |
| 1 | 自动求解 |
| ≥2 | 提示未知过多，无法计算 |

### 4.3 边界情况

| 情况 | 处理 |
|------|------|
| P = 0 且求 i 或 n | 报错（不能做分母） |
| 1 + i = 0 且求 P | 报错 |
| F/P < 0 且 n 为偶数 | 报错（无实数解） |
| F/P ≤ 0 且求 n | 报错（不能取对数） |
| 1 + i ≤ 0 且求 n | 报错 |
| R = 0 且求 M | 报错（M 无法确定） |

## 五、程序结构

```
复利计算器
│
├── get_value()          询问用户输入（数值或"未知"）
│
├── solve_i()            求解每期利率 i（处理偶次方双根）
│
├── solve_basic()        基础模式：F = P(1+i)^n
│
├── compute_ear()        由 R、M 计算 EAR
│
├── solve_ear_mode()     EAR 模式：EAR = (1+R/M)^M - 1
│                         F = P(1+EAR)^t
│
└── main()               主程序，选择模式并调度
```

### 5.1 基础模式流程图

```
开始
  │
  ▼
输入 F, P, i, n（数值或未知）
  │
  ▼
统计未知量个数
  │
  ├── 0 个 → 提示无需计算
  ├── ≥2 个 → 提示无法计算
  └── 1 个 → 判断是哪个变量
                │
                ├── F → F = P(1+i)^n
                ├── P → P = F/(1+i)^n
                ├── i → 处理双根，输出所有实数解
                └── n → n = ln(F/P)/ln(1+i)
  │
  ▼
输出结果
结束
```

### 5.2 EAR 模式流程图

```
开始
  │
  ▼
输入 F, P, R, M, EAR, t（数值或未知）
  │
  ▼
统计未知量个数
  │
  ├── 0 个 → 提示无需计算
  ├── ≥2 个 → 提示无法计算
  └── 1 个 → 判断是哪个变量
                │
                ├── EAR → (1+R/M)^M - 1
                ├── R   → M×[(1+EAR)^(1/M) - 1]
                ├── M   → 数值二分法求解
                ├── F   → P(1+EAR)^t 或 P(1+R/M)^(Mt)
                ├── P   → F/(1+EAR)^t 或 F/(1+R/M)^(Mt)
                └── t   → ln(F/P)/ln(1+EAR)
  │
  ▼
输出结果
结束
```

## 六、使用示例

### 示例 1：基础模式求 F

**输入：**

```
模式：1
F = 未知
P = 1000
i = 0.05
n = 10
```

**输出：**

```
F = P × (1 + i)^n = 1000.0 × (1 + 0.05)^10 = 1628.894627
```

### 示例 2：基础模式求 n

**输入：**

```
模式：1
F = 2000
P = 1000
i = 0.05
n = 未知
```

**输出：**

```
n = ln(F/P) / ln(1 + i) = ln(2000.0/1000.0) / ln(1 + 0.05) = 14.206699
```

### 示例 3：基础模式求 i（双根情况）

**输入：**

```
模式：1
F = 121
P = 100
i = 未知
n = 2
```

**输出：**

```
方程：(1 + i)^2.0 = F / P = 121.0 / 100.0 = 1.21
求解：1 + i = ±(1.21)^(1/2.0)
结果：
  解 1: i = 0.100000  （即 10.0000%）
  解 2: i = -2.100000  （即 -210.0000%）

说明：n 为偶数时，方程有两个数学解。
      其中使 i < -100% 的解在金融上通常无意义。

金融上有意义的解（i > -100%）：
  i = 0.100000  （即 10.0000%）
```

### 示例 4：EAR 模式由 R、M 求 EAR

**输入：**

```
模式：2
F = 未知
P = 未知
R = 0.12
M = 12
EAR = 未知
t = 未知
```

**输出：**

```
EAR = (1 + R/M)^M - 1
    = (1 + 0.12/12)^12 - 1
    = 0.126825  （即 12.6825%）
```

### 示例 5：EAR 模式由 EAR 反求 R

**输入：**

```
模式：2
F = 未知
P = 未知
R = 未知
M = 12
EAR = 0.126825
t = 未知
```

**输出：**

```
R = M × [(1 + EAR)^(1/M) - 1]
  = 12 × [(1 + 0.126825)^(1/12) - 1]
  = 0.120000  （即 12.0000%）
```

### 示例 6：未知过多

**输入：**

```
模式：1
F = 未知
P = 未知
i = 0.05
n = 10
```

**输出：**

```
未知变量过多（F, P），无法计算。
```

## 七、常见 M 取值参考

| 复利频率 | M 值 |
|----------|------|
| 每年 | 1 |
| 每半年 | 2 |
| 每季度 | 4 |
| 每月 | 12 |
| 每周 | 52 |
| 每日 | 365 |

**M 越大，EAR 与 R 的差距越大。**

例如 $R = 12\%$：

| M | EAR |
|---|-----|
| 1 | 12.0000% |
| 2 | 12.3600% |
| 4 | 12.5509% |
| 12 | 12.6825% |
| 365 | 12.7475% |

## 八、扩展方向

1. **连续复利**：当 $M \to \infty$ 时，$EAR = e^R - 1$。
2. **整数 M 推荐**：给定 R 和 EAR，尝试常见 M 值（1、2、4、12、365），返回最接近的整数。
3. **图形界面**：用 Tkinter 或 Web 前端替代命令行交互。
4. **现金流扩展**：支持多期不等额现金流（NPV、IRR）。
5. **单位换算**：支持月利率、日利率与年利率互转。

## 九、总结

本计算器围绕 $F = P(1+i)^n$ 和 $EAR = (1+R/M)^M - 1$ 两条主线，具备以下特点：

- ✅ 支持逐个输入变量，自动识别未知量
- ✅ 正确处理偶次方求 i 时的双根情况
- ✅ 区分数学解与金融有意义的解
- ✅ 提供基础模式与 EAR 模式两种口径
- ✅ 处理各类边界情况，避免非法运算
- ✅ 输出详细计算过程，便于核对

核心恒等式：

$$(1+EAR)^t = \left(1+\frac{R}{M}\right)^{Mt} = (1+i)^n$$

掌握这条恒等式，就能在年利率、期利率、有效年利率三种口径之间自由切换。
