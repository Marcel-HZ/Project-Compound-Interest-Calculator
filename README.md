# 复利、年金与投资项目评价计算器

一个命令行金融计算器，支持 **基础复利**、**有效年利率（EAR）**、**连续复利**、**普通年金** 和 **投资项目评价** 五大模式。用户逐个输入变量（数值、百分数或"未知"），程序自动识别唯一未知量并求解。

## 功能特性

- ✅ 支持五种计算模式
- ✅ 逐个询问变量，未知的输入"未知"
- ✅ 支持百分号输入（如 `5%`、`12.5%`、`-3%`）
- ✅ 自动识别唯一未知量并求解
- ✅ 迭代求解：支持变量间的依赖链（如已知 R、M 自动推出 EAR，再推出 F）
- ✅ 正确处理偶次方求 i 时的双根情况
- ✅ 区分数学解与金融有意义的解
- ✅ 求 i 时使用二分法数值求解
- ✅ 输出详细计算过程，便于核对
- ✅ 模块化设计，便于扩展

## 五种计算模式

### 模式 1：基础复利

$$F = P \times (1+i)^n$$

四种变形：

| 求解 | 公式 |
|------|------|
| F | $F = P(1+i)^n$ |
| P | $P = \dfrac{F}{(1+i)^n}$ |
| i | $i = \left(\dfrac{F}{P}\right)^{1/n} - 1$ |
| n | $n = \dfrac{\ln(F/P)}{\ln(1+i)}$ |

**变量：** `F`、`P`、`i`、`n`

### 模式 2：有效年利率（EAR）

$$EAR = \left(1 + \frac{R}{M}\right)^{M} - 1$$

$$F = P \times (1+EAR)^t$$

反解名义利率：

$$R = M \times \left[(1+EAR)^{1/M} - 1\right]$$

**变量：** `F`、`P`、`R`、`M`、`EAR`、`t`

**依赖链：**

- `R` 和 `M` 已知 → 可求 `EAR`
- `EAR`、`t`、`P` 已知 → 可求 `F`
- `R`、`M`、`t`、`P` 已知 → 可求 `F`

### 模式 3：连续复利

$$F = P \times e^{rt}$$

四种变形：

| 求解 | 公式 |
|------|------|
| F | $F = P \times e^{rt}$ |
| P | $P = F \times e^{-rt}$ |
| r | $r = \dfrac{\ln(F/P)}{t}$ |
| t | $t = \dfrac{\ln(F/P)}{r}$ |

**变量：** `F`、`P`、`r`、`t`

### 模式 4：普通年金（后付年金）

**终值公式：**

$$F = A \times \frac{(1+i)^n - 1}{i}$$

**现值公式：**

$$P = A \times \frac{1 - (1+i)^{-n}}{i}$$

**反求年金 A：**

$$A = F \times \frac{i}{(1+i)^n - 1}$$

$$A = P \times \frac{i}{1 - (1+i)^{-n}}$$

**变量：** `A`、`i`、`n`、`F`（终值型）或 `P`（现值型）

**子模式：**

- 终值型：$F = A \times \dfrac{(1+i)^n - 1}{i}$
- 现值型：$P = A \times \dfrac{1 - (1+i)^{-n}}{i}$

### 模式 5：投资项目评价

#### 平均收益率（AAR）

$$AAR = \frac{\text{年平均净利润}}{\text{初始投资额}}$$

#### 回收期（Payback Period）

累计现金流入首次 ≥ 初始投资所需的年数：

$$\text{回收期} = t - 1 + \frac{|\text{累计净现金流}_{t-1}|}{\text{第 } t \text{ 年现金流}}$$

#### 贴现回收期（Discounted Payback Period）

把每期现金流按必要收益率 $r$ 贴现后，再算回收期：

$$PV_t = \frac{CF_t}{(1+r)^t}$$

#### 净现值（NPV）

$$NPV = \sum_{t=1}^{n} \frac{CF_t}{(1+r)^t} - |CF_0|$$

#### 盈利指数（PI，净现值型）

$$PI = \frac{NPV}{|CF_0|}$$

#### 现值指数（PI，现值型）

$$PI = \frac{\sum_{t=1}^{n} \frac{CF_t}{(1+r)^t}}{|CF_0|} = \frac{NPV}{|CF_0|} + 1$$

#### XNPV（不定期现金流净现值）

$$XNPV = \sum_{i=1}^{N} \frac{CF_i}{(1+r)^{(d_i - d_1)/365}}$$

#### 内部收益率（IRR）

使 $NPV = 0$ 的折现率 $r$：

$$\sum_{t=1}^{n} \frac{CF_t}{(1+IRR)^t} - |CF_0| = 0$$

用二分法数值求解。

---

## 三种口径的等价性

基础复利、EAR、连续复利描述的是同一个增长过程：

$$(1+EAR)^t = e^{rt} = \left(1+\frac{R}{M}\right)^{Mt} = (1+i)^n$$

其中：

- 每期利率 $i = R / M$
- 总期数 $n = M \times t$
- 连续复利利率 $r = \ln(1 + EAR)$

## 关键问题处理

### 偶次方双根问题

当求解 $i$ 时，方程为：

$$(1+i)^n = \frac{F}{P}$$

设 $x = 1+i$，则 $x^n = F/P$。实数解情况如下：

| n 的奇偶 | F/P 符号 | 实数解 |
|----------|----------|--------|
| 奇数 | 正 | 一个正根 |
| 奇数 | 负 | 一个负根 |
| 偶数 | 正 | **两个根** $x = \pm(F/P)^{1/n}$ |
| 偶数 | 负 | 无实数解 |

**示例：**

$$121 = 100(1+i)^2 \Rightarrow 1+i = \pm 1.1 \Rightarrow i = 10\% \text{ 或 } -210\%$$

- $i = 10\%$：金融上有意义
- $i = -210\%$：数学上有解，但意味着本金亏光并倒欠，金融上无意义

程序会**同时列出两个解**，并标注哪些是金融上有意义的解。

### 年金求 i 的数值方法

普通年金求 $i$ 时没有解析解，程序使用**二分法**在 $(-0.9999, 10)$ 区间内搜索：

对于终值型：

$$f(i) = A \times \frac{(1+i)^n - 1}{i} - F = 0$$

对于现值型：

$$g(i) = A \times \frac{1 - (1+i)^{-n}}{i} - P = 0$$

### IRR 的数值方法

IRR 同样使用二分法，在 $(-0.9999, 10)$ 区间内寻找使 $NPV = 0$ 的折现率。

### 边界情况

| 情况 | 处理 |
|------|------|
| P = 0 且求 i 或 n | 报错（不能做分母） |
| 1 + i = 0 且求 P | 报错 |
| F/P < 0 且 n 为偶数 | 报错（无实数解） |
| F/P ≤ 0 且求 n | 报错（不能取对数） |
| 1 + i ≤ 0 且求 n | 报错 |
| R = 0 且求 M | 报错（M 无法确定） |
| A = 0 且求 i | 报错（数值法可能无解） |
| n = 0 且求 i | 报错（不能做分母） |
| 累计现金流入未达初始投资 | 回收期无法计算 |
| IRR 无解 | 报错 |

## 指标之间的逻辑关系

| 指标 | 判断标准 | 与 NPV 的关系 |
|------|----------|---------------|
| NPV | > 0 可行 | 基准 |
| IRR | > 必要收益率 可行 | NPV = 0 时的折现率 |
| PI（NPV型） | > 0 可行 | PI = NPV / \|CF0\| |
| PI（现值型） | > 1 可行 | PI = NPV / \|CF0\| + 1 |
| 回收期 | 越短越好 | 不考虑货币时间价值 |
| 贴现回收期 | 越短越好 | 考虑货币时间价值 |
| AAR | 越高越好 | 基于会计利润，非现金流 |

**核心恒等式：**

$$NPV = \sum_{t=1}^{n} \frac{CF_t}{(1+r)^t} - |CF_0|$$

$$IRR: \quad NPV(IRR) = 0$$

$$PI_{\text{现值型}} = \frac{PV}{|CF_0|} = PI_{\text{NPV型}} + 1$$

## 连续复利与 EAR 的换算

| 已知 | 求 | 公式 |
|------|-----|------|
| r | EAR | $EAR = e^r - 1$ |
| EAR | r | $r = \ln(1 + EAR)$ |

例如：

- $r = 5\%$ → $EAR = e^{0.05} - 1 = 5.1271\%$
- $EAR = 5\%$ → $r = \ln(1.05) = 4.8790\%$

## 总结

本计算器围绕以下核心公式：

- **基础复利：** $F = P(1+i)^n$
- **有效年利率：** $EAR = (1+R/M)^M - 1$
- **连续复利：** $F = P \times e^{rt}$
- **普通年金终值：** $F = A \times \dfrac{(1+i)^n - 1}{i}$
- **普通年金现值：** $P = A \times \dfrac{1 - (1+i)^{-n}}{i}$
- **净现值：** $NPV = \sum \dfrac{CF_t}{(1+r)^t} - |CF_0|$
- **内部收益率：** $NPV(IRR) = 0$

具备以下特点：

- ✅ 支持五种计算模式
- ✅ 逐个输入变量，自动识别未知量
- ✅ 支持百分号输入
- ✅ 迭代求解，支持依赖链
- ✅ 正确处理偶次方双根
- ✅ 区分数学解与金融有意义的解
- ✅ 求 i、IRR 时使用二分法数值求解
- ✅ 处理各类边界情况
- ✅ 输出详细计算过程
- ✅ 模块化设计，便于扩展

核心恒等式：

$$(1+EAR)^t = e^{rt} = \left(1+\frac{R}{M}\right)^{Mt} = (1+i)^n$$

掌握这条恒等式，就能在年利率、期利率、有效年利率、连续复利利率四种口径之间自由切换。
