# 复利与年金计算器

一个命令行金融计算器，支持**基础复利**、**有效年利率（EAR）**、**连续复利**和**普通年金**四种模式。用户逐个输入变量（数值、百分数或"未知"），程序自动识别唯一未知量并求解；支持百分号输入，例如 `5%` 会被自动识别为 `0.05`。

---

## 功能特性

- ✅ 支持四种计算模式
- ✅ 逐个询问变量，未知的输入"未知"
- ✅ 支持百分号输入（如 `5%`、`12.5%`、`-3%`）
- ✅ 自动识别唯一未知量并求解
- ✅ 迭代求解：支持变量间的依赖链（如已知 R、M 自动推出 EAR，再推出 F）
- ✅ 正确处理偶次方求 i 时的双根情况
- ✅ 区分数学解与金融有意义的解
- ✅ 求 i 时使用二分法数值求解
- ✅ 输出详细计算过程，便于核对

---

## 四种计算模式

### 模式 1：基础复利

$$F = P \times (1+i)^n$$

四种变形：

| 求解 | 公式 |
|------|------|
| F | $F = P(1+i)^n$ |
| P | $P = \dfrac{F}{(1+i)^n}$ |
| i | $i = \left(\dfrac{F}{P}\right)^{1/n} - 1$ |
| n | $n = \dfrac{\ln(F/P)}{\ln(1+i)}$ |

**变量：** `F`、`P`、`i`、`n`

### 模式 2：有效年利率（EAR）

$$EAR = \left(1 + \frac{R}{M}\right)^{M} - 1$$

$$F = P \times (1+EAR)^t$$

反解名义利率：

$$R = M \times \left[(1+EAR)^{1/M} - 1\right]$$

**变量：** `F`、`P`、`R`、`M`、`EAR`、`t`

**依赖链：**

- `R` 和 `M` 已知 → 可求 `EAR`
- `EAR`、`t`、`P` 已知 → 可求 `F`
- `R`、`M`、`t`、`P` 已知 → 可求 `F`

### 模式 3：连续复利

$$F = P \times e^{rt}$$

四种变形：

| 求解 | 公式 |
|------|------|
| F | $F = P \times e^{rt}$ |
| P | $P = F \times e^{-rt}$ |
| r | $r = \dfrac{\ln(F/P)}{t}$ |
| t | $t = \dfrac{\ln(F/P)}{r}$ |

**变量：** `F`、`P`、`r`、`t`

### 模式 4：普通年金（后付年金）

**终值公式：**

$$F = A \times \frac{(1+i)^n - 1}{i}$$

**现值公式：**

$$P = A \times \frac{1 - (1+i)^{-n}}{i}$$

**反求年金 A：**

$$A = F \times \frac{i}{(1+i)^n - 1}$$

$$A = P \times \frac{i}{1 - (1+i)^{-n}}$$

**变量：** `A`、`i`、`n`、`F`（终值型）或 `P`（现值型）

**子模式：**

- 终值型：$F = A \times \frac{(1+i)^n - 1}{i}$
- 现值型：$P = A \times \frac{1 - (1+i)^{-n}}{i}$

---

## 三种口径的等价性

基础复利、EAR、连续复利描述的是同一个增长过程：

$$(1+EAR)^t = e^{rt} = \left(1+\frac{R}{M}\right)^{Mt} = (1+i)^n$$

其中：

- 每期利率 $i = R / M$
- 总期数 $n = M \times t$
- 连续复利利率 $r = \ln(1 + EAR)$

```
模式：1
F = 未知
P = 1000

```

**输出：**

```
F = P × (1 + i)^n = 1000.0 × (1 + 0.05)^10 = 1628.894627
```

### 示例 2：基础模式求 i（双根情况）

**输入：**

```
模式：1
F = 121
P = 100
i = 未知
n = 2
```

**输出：**

```
方程：(1 + i)^2.0 = F / P = 121.0 / 100.0 = 1.21
求解：1 + i = ±(1.21)^(1/2.0)
结果：
  解 1: i = 0.100000  （即 10.0000%）
  解 2: i = -2.100000  （即 -210.0000%）

说明：n 为偶数时，方程有两个数学解。
      其中使 i < -100% 的解在金融上通常无意义。

金融上有意义的解（i > -100%）：
  i = 0.100000  （即 10.0000%）
```

### 示例 3：EAR 模式由 R、M 求 EAR 和 F

**输入：**

```
模式：2
F = 未知
P = 100
R = 5%
M = 100
EAR = 未知
t = 1
```

**输出：**

```
求解过程：
  EAR = (1 + R/M)^M - 1 = (1 + 0.05/100)^100 - 1 = 0.051265  （即 5.1265%）
  F = P × (1+EAR)^t = 100.0 × (1+0.051265)^1 = 105.126497

最终结果：
  F    = 105.126497
  P    = 100.000000
  R    = 0.050000  （即 5.0000%）
  M    = 100.000000
  EAR  = 0.051265  （即 5.1265%）
  t    = 1.000000
```

### 示例 4：连续复利

```
模式：3

t = 1
```

**输出：**

```
求解过程：
  F = P × e^(rt) = 100.0 × e^(0.05×1.0) = 105.127110

最终结果：
  F    = 105.127110
  P    = 100.000000
  r    = 0.050000  （即 5.0000%）
```

## 关键问题处理

### 偶次方双根问题

当求解 $i$ 时，方程为：

$$(1+i)^n = \frac{F}{P}$$

设 $x = 1+i$，则 $x^n = F/P$。实数解情况如下：

| n 的奇偶 | F/P 符号 | 实数解 |
|----------|----------|--------|
| 奇数 | 正 | 一个正根 |
| 奇数 | 负 | 一个负根 |
| 偶数 | 正 | **两个根** $x = \pm(F/P)^{1/n}$ |
| 偶数 | 负 | 无实数解 |

**示例：**

$$121 = 100(1+i)^2 \Rightarrow 1+i = \pm 1.1 \Rightarrow i = 10\% \text{ 或 } -210\%$$

- $i = 10\%$：金融上有意义
- $i = -210\%$：数学上有解，但意味着本金亏光并倒欠，金融上无意义

程序会**同时列出两个解**，并标注哪些是金融上有意义的解。

### 年金求 i 的数值方法

普通年金求 $i$ 时没有解析解，程序使用**二分法**在 $(-0.9999, 10)$ 区间内搜索：

对于终值型：

$$f(i) = A \times \frac{(1+i)^n - 1}{i} - F = 0$$

对于现值型：

$$g(i) = A \times \frac{1 - (1+i)^{-n}}{i} - P = 0$$

### 边界情况

| 情况 | 处理 |
|------|------|
| P = 0 且求 i 或 n | 报错（不能做分母） |
| 1 + i = 0 且求 P | 报错 |
| F/P < 0 且 n 为偶数 | 报错（无实数解） |
| F/P ≤ 0 且求 n | 报错（不能取对数） |
| 1 + i ≤ 0 且求 n | 报错 |
| R = 0 且求 M | 报错（M 无法确定） |
| A = 0 且求 i | 报错（数值法可能无解） |
| n = 0 且求 i | 报错（不能做分母） |

## 连续复利与 EAR 的换算

| 已知 | 求 | 公式 |
|------|-----|------|
| r | EAR | $EAR = e^r - 1$ |
| EAR | r | $r = \ln(1 + EAR)$ |

例如：

- $r = 5\%$ → $EAR = e^{0.05} - 1 = 5.1271\%$
- $EAR = 5\%$ → $r = \ln(1.05) = 4.8790\%$

---

## 连续复利的实际意义

连续复利在金融数学中非常重要：

1. **理论极限**：所有离散复利的上限。
2. **期权定价**：Black-Scholes 公式使用连续复利。
3. **随机过程**：几何布朗运动的解就是 $S_t = S_0 e^{rt}$。
4. **利率建模**：连续复利利率在理论模型中比名义利率更自然。

## 总结

本计算器围绕以下核心公式：

- **基础复利：** $F = P(1+i)^n$
- **有效年利率：** $EAR = (1+R/M)^M - 1$
- **连续复利：** $F = P \times e^{rt}$
- **普通年金终值：** $F = A \times \dfrac{(1+i)^n - 1}{i}$
- **普通年金现值：** $P = A \times \dfrac{1 - (1+i)^{-n}}{i}$

具备以下特点：

- ✅ 支持四种计算模式
- ✅ 逐个输入变量，自动识别未知量
- ✅ 支持百分号输入
- ✅ 迭代求解，支持依赖链
- ✅ 正确处理偶次方双根
- ✅ 区分数学解与金融有意义的解
- ✅ 求 i 时使用二分法数值求解
- ✅ 处理各类边界情况
- ✅ 输出详细计算过程

核心恒等式：

$$(1+EAR)^t = e^{rt} = \left(1+\frac{R}{M}\right)^{Mt} = (1+i)^n$$

掌握这条恒等式，就能在年利率、期利率、有效年利率、连续复利利率四种口径之间自由切换。
